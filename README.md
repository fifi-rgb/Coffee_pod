# ☕ Tassimo Price Tracker

An n8n workflow that checks Tassimo coffee pod prices every six hours, keeps a price history, and sends Gmail alerts when a product meets your target or reaches a new low. Alerts include the price per drink, accounting for milk drinks that use two pods per drink.

## How it works

Every 6 hours → list products → fetch product pages politely → parse and compare prices → send Gmail alerts for deals.

## Prerequisites

- Docker and Docker Compose
- A Gmail account to send alerts from, and the recipient email address where you want to receive them

## Setup

1. Clone the repository and enter it:

   ```bash
   git clone <repository-url> tassimo-price-tracker
   cd tassimo-price-tracker
   ```

2. Create your local environment file:

   ```bash
   cp .env.example .env
   ```

   Set `GMAIL_TO` to the address that should receive alerts and replace `N8N_ENCRYPTION_KEY` with a private key generated by `openssl rand -hex 32`.

3. Start n8n:

   ```bash
   docker compose up -d
   ```

4. Open [http://localhost:5678](http://localhost:5678) and create your n8n account.

5. Import the workflow:

   ```bash
   ./scripts/import.sh
   ```

6. In n8n, create a Gmail OAuth2 credential and connect the Gmail account you want to send from. Select that credential on the Gmail Alert node. Follow the [n8n Gmail credential setup guide](https://docs.n8n.io/integrations/builtin/credentials/google/); self-hosted n8n may require configuring a Google OAuth client.

7. Test the workflow by temporarily setting a product's `targetPrice` to `99` in [src/product-list.js](./src/product-list.js), running `node scripts/sync.js build`, and executing the workflow. Restore the target price, build again, and activate the workflow.

## Editing the watchlist

Edit the `products` array in [src/product-list.js](./src/product-list.js). Set each product's name, retailer, product-page URL, target price in GBP, and drinks per pack. Milk drinks usually make one drink from every two pods, so use `pods ÷ 2` for `drinksPerPack` (for example, 16 latte pods make 8 drinks). Most black coffee pods make one drink per pod.

After editing the list or Code-node source, run:

```bash
node scripts/sync.js build
```

Commit both the source file and the synchronized workflow JSON.

## Editing in the n8n UI

Export UI edits with the workflow ID:

```bash
./scripts/export.sh <workflow-id>
```

This extracts the Code-node bodies into `src/` and rebuilds the workflow JSON. Export once after the first import so later imports update the same workflow instead of duplicating it.

## Troubleshooting

| Problem | What to try |
|---|---|
| Price not found | Add a product-specific `priceRegex` to that product in `src/product-list.js`. Its first capture group must contain the price. |
| Captcha or Access Denied | Try another shop or a scraping API that is permitted by the retailer. |
| Price rendered by JavaScript | Use a headless browser service such as Browserless to retrieve the rendered page. |
| Wrong price found | Add a more specific `priceRegex` and verify its first capture group against the product page. |

## Security

- Gmail OAuth credentials are stored by n8n. The exported workflow JSON references the credential but does not contain its access token or client secret.
- `.env` contains local configuration and is ignored by git. Never commit it or share its contents.
- Keep your n8n encryption key private; it protects credentials stored by n8n.
- The sample product URLs point to Amazon UK. Check that each listing still matches the product and pack size you want; retailers may restrict automated page requests.

## Notes

- Price history is stored in n8n workflow static data and is **only saved during active/scheduled runs**, not manual test runs.
- Be polite to shops: check every few hours, not every minute.
